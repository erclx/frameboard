# Context entry standards

## Shape

- Write one-fact bullets under each H3, and keep prose to the one- or two-sentence Overview.
- Write each bullet as a complete sentence carrying its own reason, as in "X, so Y" or "X, because Z".
- Hold a run to at most 5 bullets of about 250 characters each, and open each item of a peer list with a bold label.

## Lifetime

- Remove this rule once canon's context standard carries the same shape, per erclx/canon#2400.
