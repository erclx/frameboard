# Clean

Flat boxes, one accent, and Geist, for a screen that should read as a product rather than a sketch.

## Reach for

- `.kit-card` for a box holding one idea or one control group
- `.kit-note` for a thought pinned beside the work
- `.kit-button`, plus `.kit-primary` on the one action that matters
- `.kit-line` on an SVG `path` for an arrow or a connector
- `.kit-muted` for secondary text

## Keep to

- Color through `--accent`, `--surface`, `--text`, `--muted`, `--border`, `--line`, and `--note` alone, so dark mode follows
- One primary button per group
- The `kit` page shows every part drawn in this look
