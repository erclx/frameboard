# Wireframe

Greys, dashed lines, and Geist Mono, for a layout read before any style is chosen.

## Reach for

- `.kit-card` for a region of the layout
- `.kit-note` for an annotation beside the layout
- `.kit-button`, plus `.kit-primary` on the one action that matters
- `.kit-line` on an SVG `path` for a flow arrow
- `.kit-muted` for placeholder and secondary text

## Keep to

- Greys alone, through `--accent`, `--surface`, `--text`, `--muted`, `--border`, `--line`, and `--note`, so no color decision is made yet
- Placeholder text that names what goes there, such as `Product name`, over invented copy
- The `kit` page shows every part drawn in this look
