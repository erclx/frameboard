# Board

The browser app, split into the shell, the inspector, and the hand actions

- [Hand actions](hand-actions.md): Selection, undo and redo, hide and lock, arranging and snapping, copying a frame as an image, right-click menus, and the keys behind each
- [Inspector](inspector.md): Controls for a selected frame, several frames, or an element, the bar a new control clears, and what a hand edit writes
- [Board server](server.md): Folder watcher, socket hub, claims record, write access, and the HTTP routes behind the board
- [Board shell](shell.md): Home view, panels, toolbar, canvas, notes, Edit and Play, agent change marks, find, the command palette, and claimed frames
