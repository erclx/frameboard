controls-edit-720. Edit mode. The agent or the developer draws three sliders beside a photo. Each slider is an ordinary range input carrying one line, data-binds="#photo --contrast", and the board draws the link as a dashed line and a tag.

The photo's CSS reads the three values: filter: brightness(var(--brightness)) contrast(var(--contrast)) grayscale(var(--grayscale)). Nothing else in the file is special.
