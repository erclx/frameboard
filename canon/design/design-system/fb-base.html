Rules

  1. Blue means selectedNever a decoration, never a second meaning
  2. Purple is always an agentClaims, sessions, agent replies
  3. Red only on DeleteSo it stays rare enough to notice
  4. Greys do the layoutPanels, fields, and rows differ by one grey step
  5. Names are shadcn'sPlus claim, note, faint, success, and guide
