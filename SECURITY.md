# Security policy

Frameboard runs a local server that reads and writes files in your project, so a flaw in what it serves or writes is a security issue.

## Reporting a vulnerability

Report it privately through GitHub's [private vulnerability reporting](https://github.com/erclx/frameboard/security/advisories/new). Do not open a public issue for it.

Include the Frameboard version, your OS, and the steps that reproduce the problem. You get a reply in the advisory thread.

## Supported versions

Only the latest release receives fixes.
